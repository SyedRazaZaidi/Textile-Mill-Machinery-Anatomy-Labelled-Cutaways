# Textile Mill Machinery Anatomy
Labelled engineering cutaways of machines used in a textile mill.
These plates show the main parts of each machine with printed names and leader lines. They are for learning, teaching, and portfolio use.
**Author:** Syed Raza Abbas Zaidi
## What this repository is
A catalogue of original labelled cutaway illustrations covering a vertical mill path:
- fibre preparation and spinning
- warp preparation and weaving
- dyeing and printing
- finishing and coating
- cut and sew
- utilities (air, heat, effluent)
- shade lab and loom shedding (for study of “shading” in mills)
## What this repository is not
- Not photographs of a real mill
- Not X-rays or NDT scans
- Not an OEM service manual
- Not a claim that any brand, model, or spare-part number is shown
- Not a software product or sensor dataset
If a part name on a plate disagrees with a manufacturer drawing, the manufacturer drawing wins.

| `02_Warp_Prep_and_Weaving` | Warper, sizing, air-jet, rapier, water-jet, projectile, inspection, dobby, jacquard |
| `03_Dyeing_and_Printing` | Jet dye, jigger, package dye, indigo range, rotary print |

| `06_Utilities` | Compressor and dryer, boiler / thermic, ETP |
| `07_Shade_Lab_and_Shedding` | Colour / shade lab and loom shedding study plates |
## File names
Files start with a short class code, then the machine name:
```text
WV-AJ_Air_Jet_Loom_Labeled_Cutaway.png
SP-RING_Ring_Frame_Labeled_Cutaway.png
FN-STN_Stenter_Labeled_Cutaway.png
UT-AIR_Compressor_Dryer_Labeled_Cutaway.png
The code is only a filing ID. It is not an OEM model number.

How to use
Open any PNG as a study plate.
Keep the folder names if you share the set, so spinning stays separate from weaving.
Do not treat a label as a spare-parts order list.
